# Code of conduct

Rounder is a small project and we'd like it to stay a friendly place to ask questions and send fixes.

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, insults, discrimination or unwelcome sexual attention, in any form.
- Keep private things private: don't post other people's personal information or files.
- Help newcomers; everybody started somewhere.

This applies in issues, pull requests, discussions and any other project space. If someone breaks these rules, email
hello@roundertools.com. Reports are handled in confidence. The maintainer may edit or remove comments, and block people
who keep breaking the rules.

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
